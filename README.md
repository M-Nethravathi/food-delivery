## Description
This project is a responsive and elegant Food Delivery frontend built with **React**. It demonstrates category browsing, an always-visible cart box, dynamic total calculation with delivery charges, and a polished hotel-style UI ideal for showcasing in a portfolio.

---

## Features
- Category filtering (Fast Food, Vegetarian, Seafood, Desserts, Drinks, etc.)
- Add / remove items from cart
- Live total calculation and delivery charges
- Sticky / fixed cart box visible on the page
- Elegant dark-gold theme and large title (portfolio-ready)
- Responsive layout for desktop and mobile

---

## Technologies
- React.js
- JavaScript (ES6+)
- CSS (no Tailwind required)
- Deployed on Vercel / Netlify (recommended)
